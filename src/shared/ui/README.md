# Shared UI

Reusable presentation components used across features.

- `PageHeader` — gradient header with icon tile, eyebrow, title, description, actions and optional children.
- `FilterChip`, `FilterChipGroup`, `SearchField` — consistent filtering controls.
- `EmptyState` — empty and no-result panel with an optional action.
- `RevealItem` — `li` that fades up as it enters the viewport (staggered by index).
- `TiltCard` — link card with pointer-driven 3D tilt (mouse only, respects reduced motion).
- `EmbeddedSimulation` — framed iframe with loading, timeout and full-screen states.
- `RemoteThumbnail`, `SubjectIcon`, `NotFoundPage` — small shared pieces.
