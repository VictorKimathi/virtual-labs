# Guided lessons

The guided page has seven CBE-style steps. Lesson text, outcomes, resources, procedure and the simulations each lesson links to live in `data/lessons.ts`. Ohm's Law, Plant Cells and the three Chemistry lessons (Acids & Bases, Acid–Base Titration, Separating Mixtures) have full content, an introduction illustration and a linked practical. Other lessons show a general lesson outline.
